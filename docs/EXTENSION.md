# Signature extension - planned X2

Selected direction: proposal experiments in GigSim. Implementation is pending.

Compare two grounded proposal strategies: an evidence-first opening and a concise problem-first opening. Hold model configuration, retrieval, pricing and compliance constant. Predeclare the primary metric as reply rate, randomization seed and sample size; assign jobs to arms within persona/category strata. Keep the held-out evaluation separate from prompt iteration.

Report arm sizes, replies, effect size with confidence interval and a Fisher exact significance test when counts are small. A non-significant difference is a valid result. Neither arm can bypass approval or use fabricated evidence. Capture the setup and raw outcomes under evals/results before writing conclusions.
